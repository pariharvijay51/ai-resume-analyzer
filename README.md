# AI Resume Analyzer & Job Matcher
React + Express + MySQL + Gemini.

## Setup
1. Install Node.js 18+ and MySQL.
2. cd backend && npm install && copy .env.example to .env and fill in MySQL password + GEMINI_API_KEY
3. npm start   (API on :5000, database and tables are created automatically)
4. New terminal: cd frontend && npm install && npm run dev
5. Open http://localhost:5173
